모먼티 · MOMENTY 개인정보처리방침

수정일: 2026년 10월 6일

개인정보 수집

모먼티는 회원가입, 광고, 분석 도구를 사용하지 않으며 사진, 음악, 문구를 개발자 서버로 전송하거나 수집하지 않습니다. 영상 제작은 기기 안에서 이루어집니다.

기기에 저장하는 자료

선택한 사진과 음악의 복사본, 제목·캡션·장면 문구, 편집 설정과 초안을 앱 내부에 저장합니다. 사진과 음악은 운영체제의 선택 화면을 통해 사용자가 지정한 자료만 가져옵니다. 완성 영상은 사용자가 저장 또는 공유를 선택할 때 사진 앱이나 기기의 미디어 저장소에 저장합니다.

공유와 백업

공유를 실행하면 사용자가 선택한 앱이나 서비스로 영상이 전달되며 해당 서비스의 정책이 적용됩니다. iPhone에서는 기기 설정에 따라 앱의 자료가 iCloud 또는 컴퓨터 백업에 포함될 수 있습니다. Android 버전은 앱 내부 자료의 자동 클라우드 백업과 기기 간 이전을 비활성화합니다.

보관과 삭제

초안은 기기에 보관됩니다. 앱 삭제 시 기기의 앱 내부 자료가 삭제됩니다. 사진 앱·파일 앱에 저장하거나 공유한 영상 및 별도 백업은 해당 앱이나 서비스에서 직접 삭제해야 합니다. 초안을 삭제하면 해당 초안의 앱 내부 자료를 정리합니다.

배경음악

기본 배경음은 개발자가 Suno로 제작해 앱에 포함한 음악입니다. 사용자 자료를 Suno에 보내지 않으며 앱 사용 시 Suno 계정이 필요하지 않습니다.
